# Guía de Sistemas Ciberfísicos

Guía de estudio para principiantes de las presentaciones de MR3005C (Tec de Monterrey): redes neuronales con TensorFlow y PyTorch, aprendizaje por refuerzo (Q-learning, DQN, SAC) y ROS 2.

La guía es una sola página web: [`index.html`](index.html). Se publica con GitHub Pages.

Contenido:

- **Bloque A · Redes neuronales:** neurona y capas, cómo aprende una red, TensorFlow/Keras, PyTorch, ejemplo del péndulo.
- **Bloque B · Aprendizaje por refuerzo:** fundamentos, Q-learning tabular, Deep Q-Network, Actor-Crítico y SAC.
- **Bloque C · ROS 2:** qué es ROS 2, workspace y publicador/suscriptor, depuración, lazo de control distribuido.

Cada tema incluye las correcciones a errores encontrados en las diapositivas y preguntas de autoevaluación.
